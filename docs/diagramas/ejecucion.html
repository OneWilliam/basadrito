Dónde viajan y se guardan los datos

Objetivo de ejecución: acceso directo en clientes nativos; acceso por BFF en navegador. El servidor incorpora persistencia cuando exista un requisito propio.

Moodle y Campus/Intranet son servicios distintos agrupados visualmente, no una única API. Las flechas indican uso; se omiten respuestas. SQLite guarda caché académica; el almacén protegido guarda material de sesión. PostgreSQL es una propuesta condicionada, no un servicio desplegado.

Estilo predeterminado de diagram-design. El HTML es la fuente editable; el SVG exportado acompaña la documentación.
