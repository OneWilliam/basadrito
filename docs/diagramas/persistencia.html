Cada dato tiene un almacenamiento

Propuesta de almacenamiento: la caché permite consulta sin conexión; el almacén protegido recupera acceso; las preferencias conservan configuración.

Room/SQLite es la propuesta inicial Android, con fuentes compatibles para otros destinos nativos/JVM. Keystore protege claves de cifrado, no almacena directamente cualquier token o cookie. PostgreSQL pertenece al BFF y se añade por una necesidad de datos propios. Las flechas representan destino de persistencia; no son dependencias entre secretos y datos académicos.
