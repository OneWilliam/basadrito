De una acción al estado de pantalla

Flujo previsto de una consulta con caché: la UI comunica eventos; el repositorio controla acceso y persistencia; el ViewModel publica el resultado.

Las flechas describen ejecución y retorno, no dependencias Gradle. La UI no conoce SQL: observa estado del ViewModel; este consume el contrato del repositorio. La respuesta HTTP vuelve por el adaptador. El repositorio lee o actualiza la DB y emite modelos propios. Esta vista no afirma que la caché ya esté implementada.

Estilo predeterminado de diagram-design. El HTML es la fuente editable; el SVG exportado acompaña la documentación.
