Las partes de Basadrito

Vista axonométrica en proyección dimétrica 2:1: las tres partes se separan para reconocer su responsabilidad.

La representación espacial es una ayuda de lectura. No implica que domain dependa de data, ni que presentación ejecute siempre antes que dominio. Cada parte corresponde a responsabilidades que se conectan mediante contratos. Las ubicaciones reales se muestran en la vista de ejecución.

Estilo predeterminado de diagram-design. El HTML es la fuente editable; el SVG exportado acompaña la documentación.
